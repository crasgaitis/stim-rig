# stim-rig

Printing instructions:

1. Rig (19.5in diameter)
- hoop: 1x `outer_end_neg`, 2x `outer_mid` (pos [x] and neg [x] for correct labels), 1x `outer_end_pos`
- speaker set up (1x each): `speaker_sleeve`, `speaker_front`, `speaker_ring`, `speaker_yoke`, 	
- hubs (1x each): `hub_left`, `hub_right`, `upright_left`, `upright_right` [x]
- 2x `knob_m8`
- 4x `foot_washer`

2. LED clips (technically just need 1):
- 1x `led_spider`
- 1 + 1 per clip x `knob_m4`
- `LED clip 0` mounts the LED directly inline with the hoop. (same elevation as matched LED in front of speaker), OR
- `LED clip 20` mounts the LED 20 degrees offset from the hoop. (either above or below speaker)
